# Lampa Torrent Pro

Собственный чистый плагин для Lampa. Цель проекта — поиск фильмов и сериалов через подключаемые поисковые источники, фильтры качества/озвучки, воспроизведение через облачный торрент-клиент и погода для Белгорода.

## Текущий статус

Версия 0.2.0 — чистая основа настроек.

Уже сделано:
- собственный JavaScript-каркас;
- настройки адреса поискового API;
- поле для личного ключа TorBox;
- настройки погоды и города (по умолчанию Белгород);
- в исходнике нет рекламных баннеров, аналитики, встроенных чужих API-ключей и стороннего прокси по умолчанию.

Пока НЕ реализовано:
- реальный поиск по названию;
- получение и отображение списка раздач;
- подключение TorBox и получение потоковой ссылки;
- выбор файла/серии, аудиодорожки и субтитров;
- интерфейс плеера;
- вывод прогноза погоды в интерфейсе Lampa.

Эти функции нельзя честно объявить готовыми до подключения и тестирования конкретного API поискового провайдера и облачного движка.

## Установка текущей основы

Добавить в Lampa → Настройки → Расширения/Плагины → Добавить плагин:

`https://raw.githubusercontent.com/D09081/Lampa-Torrent-Pro/main/plugin/lampa-torrent-pro.js`

## Безопасность и реклама

Проект не копирует исходный код сторонних плагинов без лицензии. Не использует встроенные чужие ключи, рекламные вставки, трекеры или неизвестный прокси. Пользователь должен указывать собственные учётные данные.

## Правовой режим

Плагин — инструмент поиска и воспроизведения. Пользователь должен иметь право получать и смотреть выбранный контент. Наличие раздачи в поисковом индексе само по себе не подтверждает законность её распространения.
