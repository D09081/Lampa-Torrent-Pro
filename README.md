# Lampa Torrent Pro

**Версия 1.9.3 — единый экран «Где смотреть».** Плагин не дублирует каталог и поиск Lampa. Его задача — помочь найти способ просмотра на карточке фильма и подключить совместимые онлайн-источники.

## Что умеет

- Кнопка **«Где смотреть»** на карточке фильма или сериала.
- Единый экран «Где смотреть»: официальные варианты, найденные сервисы по данным TMDB, онлайн-плагины и поиск открытых раздач собраны в одном меню.
- Официальные платформы (Netflix, Prime Video и другие): доступность по региону из TMDB, переход к вариантам через JustWatch. Список сервисов информационный; запуск закрытых потоков напрямую в Lampa не поддерживается. Это не обходит подписку и DRM: для воспроизведения на официальной платформе нужен её аккаунт/приложение.
- Менеджер онлайн-балансеров: по выбору пользователя загружает совместимые плагины Lampa — Online МОД, Showy, Online Cinema и Hermes Movie (Kinogo и другие).
- Выбранные плагины сохраняются в настройках Lampa и повторно загружаются при старте.
- Опциональное подключение собственного Lampac через `/online.js`; Lampac может предоставлять десятки провайдеров, включая VideoDB и Kinogo.
- Internet Archive и собственный Jackett для поиска доступных раздач; TorrServer требуется для большинства magnet/torrent потоков.
- Погода: Open-Meteo → wttr.in → резервный 7Timer через CORS proxy; координаты выбранного города сохраняются до запроса прогноза, поэтому резерв не подменяет другой город координатами Белгорода.
- В окне погоды есть ручное обновление прогноза.
- Менеджер онлайн-плагинов различает состояния загрузки, подключения и тайм-аута; после неудачной загрузки можно повторить подключение.

## Установка

Lampa → Настройки → Расширения → Добавить плагин:

`D09081.github.io/Lampa-Torrent-Pro/plugin.js` (короткая запись)

Полный адрес для установки в Lampa: `https://d09081.github.io/Lampa-Torrent-Pro/plugin.js`

Перезапустите Lampa. В меню появится **Torrent Pro**.

## Как смотреть

Экран 1.4.0 показывает найденные TMDB сервисы отдельными строками и открывает подборку вариантов для конкретного названия через JustWatch. Подключаемые онлайн-плагины по-прежнему запускают собственные интерфейсы Lampa: у них нет общего публичного API, поэтому объединять их результаты в одну выдачу без адаптеров или backend нельзя.

1. Найдите фильм штатным поиском Lampa.
2. Откройте карточку и выберите **«Где смотреть»**.
3. Для официальных сервисов откройте JustWatch.
4. Для онлайн-балансеров выберите **«Подключить онлайн-источники»** и активируйте нужный плагин. После загрузки его кнопка/источник появится в интерфейсе Lampa; выбранные плагины будут загружаться при следующем запуске.
5. Для торрентов настройте Jackett и TorrServer отдельно.

## Источники и ограничения

- **Showy** в опубликованных каталогах указывается как источник VideoDB, VideoCDN, HDVB и других; может требовать активации через Telegram. Адрес расширения HTTP, поэтому некоторые версии Lampa/webOS или сетевые настройки могут его блокировать.
- **Hermes Movie** указывается как источник Kinogo, HDRezka, Filmix и VideoCDN. Он добавляет собственную кнопку поиска источников на карточку.
- **Online МОД** и **Online Cinema** — сторонние плагины с наборами балансеров. Их доступность и качество зависят от авторов источников.
- **Lampac** — дополнительный backend; для него нужен собственный сервер. Плагин не подключается к неизвестным публичным серверам.
- **Netflix** и другие официальные платформы отображаются как варианты доступности/перехода через JustWatch. Lampa не получает закрытый поток Netflix и не заменяет подписку.
- **Fovea**: не найден подтверждённый действующий Lampa-плагин/балансер с таким названием, поэтому адрес не выдуман.
- Сторонние плагины загружают собственный код. Подключайте только те, которым доверяете; источники и права на конкретные видео проверяйте самостоятельно.

## Погода

Для Белгорода используются координаты 50.5997, 36.5983. Основной API — Open-Meteo; резерв — wttr.in; дополнительный — 7Timer через CORS proxy. При смене города кэш обновляется отдельно. Если все API недоступны из сети телевизора, плагин покажет ошибку вместо фиктивной температуры.

## Настройки

- Регион источников (RU по умолчанию).
- Город погоды (Белгород по умолчанию).
- Показ погоды.
- Адрес и ключ собственного Jackett.
- Адрес собственного Lampac-сервера (необязательно).

## Проверки

GitHub Actions выполняет синтаксическую проверку JavaScript и публикацию Pages. Это не заменяет проверку на конкретном LG webOS: запуск стороннего балансера зависит от версии Lampa, доступности его сервера и совместимости видеокодека.
