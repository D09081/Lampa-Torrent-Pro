# Lampa Torrent Pro

Плагин для Lampa с приоритетом легальных торрент-источников и дальнейшей интеграцией с TorrServer.

## Уже добавлено

- Начальный JavaScript-плагин Lampa.
- Раздел настроек Lampa Torrent Pro.
- Поля адреса TorrServer и учётных данных (если авторизация включена на сервере).
- Режим allowlist — заранее определённый список источников.
- Каталог источников: [sources.json](sources.json).
- Инструкция: [INSTALL.md](INSTALL.md).

## Установка

Добавьте в Lampa URL:
`https://raw.githubusercontent.com/D09081/Lampa-Torrent-Pro/main/plugin/lampa-torrent-pro.js`

## Источники

Стартовый список: Internet Archive, Public Domain Torrents, Blender Open Movies и Academic Torrents. Для каждого конкретного материала нужно проверять лицензию и право на распространение. Включение сайта в список не означает, что весь его контент легален.

## Дальнейшая разработка

1. Проверка соединения с TorrServer.
2. Поиск по каталогам с учётом доступных API и условий использования.
3. Карточка материала с указанием источника и лицензии.
4. Передача разрешённых torrent/magnet в TorrServer.
5. Тестирование на LG webOS.
