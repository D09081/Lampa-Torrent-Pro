# Lampa Torrent Pro

**Версия 1.0.0 — MVP.** Плагин дополняет Lampa: не создаёт собственный поиск по каталогу, а использует карточки и встроенный поиск Lampa.

## Что есть в MVP

- Отдельный понятный раздел **Torrent Pro**: премьеры, сериалы, популярное, источники и погода.
- На карточке фильма или сериала — кнопка **«Где смотреть»**.
- Доступность онлайн-кинотеатров по региону через TMDB Watch Providers. Для результата показывается переход на страницу вариантов просмотра JustWatch, если TMDB вернул ссылку.
- Поиск доступных раздач для выбранной карточки через Internet Archive и пользовательский Jackett.
- Internet Archive: выбор видеофайла и попытка онлайн-воспроизведения; права на каждый файл необходимо проверять отдельно.
- Jackett: подключаемые пользователем индексаторы; для большинства torrent/magnet-раздач требуется настроенный TorrServer.
- Погода для Белгорода по умолчанию: Open-Meteo, резервный wttr.in, обновление раз в 30 минут.

## Установка

Lampa → Настройки → Расширения/Плагины → Добавить плагин:

`https://d09081.github.io/Lampa-Torrent-Pro/plugin.js`

После установки перезапустите Lampa. Раздел **Torrent Pro** появится в меню.

## Как пользоваться

1. Найдите фильм или сериал обычным поиском Lampa.
2. Откройте карточку.
3. Нажмите **«Где смотреть»**.
4. Выберите вариант онлайн-просмотра или доступную раздачу. Для раздач Jackett настройте собственный сервер и TorrServer.

## Настройки

- **Регион** — код страны для списка онлайн-кинотеатров (по умолчанию RU).
- **Адрес Jackett / ключ Jackett** — необязательно; используйте собственный сервер. Ключ передаётся напрямую в запросе к Jackett, поэтому не используйте общий или чужой сервер.
- **Город погоды** — по умолчанию Белгород.
- **Показывать погоду** — включает или отключает виджет.

## Ограничения MVP

- Список сервисов зависит от полноты TMDB для выбранного региона. Название сервиса не гарантирует наличие подписки у пользователя; прямые ссылки на каждый кинотеатр могут не предоставляться API.
- Internet Archive и каталоги открытого кино не гарантируют права на каждый размещённый файл. Проверяйте лицензию конкретного материала.
- Jackett требует отдельного сервера и настроенных индексаторов; TorrServer необходим для большинства torrent/magnet-потоков.
- Совместимость интерфейса и воспроизведения необходимо проверить на конкретной версии Lampa и телевизоре LG webOS. GitHub Actions проверяет публикацию/структуру проекта, но не заменяет тест на телевизоре.

## Реклама и приватность

В плагине нет собственных рекламных баннеров и аналитики. Плагин не содержит встроенных чужих API-ключей. Пользователь сам задаёт адрес и ключ Jackett.

## Правовой режим

Используйте только материалы, которые вы вправе смотреть или загружать. Наличие результата в индексе, torrent-файла или каталога не подтверждает законность распространения.
