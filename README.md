# Lampa Torrent Pro

**Версия 2.0.0 — онлайн-кинотеатр на базе Lampa.** Каталог и поиск остаются штатными, а плагин добавляет главный экран Cinema OS и кнопку **«Смотреть»** на карточке, которая собирает варианты просмотра в один список.

## Что умеет

- **Главная Cinema OS:** постеры новинок и трендов сразу под заголовком, быстрый доступ (новинки, сериалы, жанры, мой список, избранное, история), управление пультом.
- **Кнопка «Смотреть»** на карточке фильма или сериала: один список вместо цепочки меню.
  1. Сверху «Рекомендуем» — лучший вариант по вашим настройкам качества и озвучки.
  2. Далее другие варианты: онлайн-просмотр из Internet Archive (только если совпали название и год) и раздачи вашего Jackett с пометками 4K / 1080p / 720p, «рус», сиды, размер.
  3. «Официальные сервисы» — где фильм доступен по подписке, аренде или покупке (TMDB, переход через JustWatch).
  4. «Онлайн-плагины Lampa» и «Подключить Jackett».
- **Воспроизведение:** онлайн-файлы Internet Archive запускаются штатным плеером Lampa сразу; раздачи — через торрент-модуль Lampa и ваш TorrServer.
- **Онлайн-плагины** (Online МОД, Showy, Online Cinema, Hermes Movie) и собственный Lampac подключаются как отдельные расширения Lampa и добавляют свои кнопки на карточку. Их результаты в общий список не объединяются: у них нет общего API.
- **Погода:** Белгород по умолчанию (Open-Meteo → wttr.in → 7Timer), отдельный пункт меню и значок в шапке.
- Мой список (локально), подбор по жанру, режим производительности для слабых телевизоров.

## Установка

Lampa → Настройки → Расширения → Добавить плагин:

`https://d09081.github.io/Lampa-Torrent-Pro/plugin.js`

Перезапустите Lampa. В левом меню появится **Cinema OS**.

## Как смотреть

1. Откройте **Cinema OS** или найдите фильм штатным поиском Lampa.
2. Откройте карточку и нажмите **«Смотреть»**.
3. Выберите «Рекомендуем» или другой вариант. Для раздач нужны ваши Jackett и TorrServer (настройки плагина или парсера Lampa).

## Источники и ограничения

- **Internet Archive** — открытый каталог, в основном свободные фильмы; новых релизов там нет.
- **Jackett и TorrServer** — ваши собственные серверы, плагин не подключает чужие индексаторы.
- **Netflix и другие платформы** показываются как доступность и переход через JustWatch; закрытый поток в Lampa не запускается, подписку это не заменяет.
- **Сторонние онлайн-плагины** загружаются из внешних адресов и выполняют собственный код с полными правами в Lampa. Online МОД подключается при каждом запуске, остальные — по вашему выбору. Плагин с адресом HTTP (Showy) требует отдельного подтверждения, так как скрипт могут подменить по дороге. Права на конкретные видео проверяйте самостоятельно.
- **Fovea**: подтверждённого действующего Lampa-плагина с таким названием не найдено, адрес не выдуман.

## Настройки

Регион (RU), город погоды (Белгород), показ погоды, адрес и ключ Jackett, адрес своего Lampac, предпочитаемые качество и озвучка, режим производительности.

## Проверки

GitHub Actions проверяет синтаксис JavaScript. Это не заменяет проверку на вашем телевизоре: запуск сторонних плагинов зависит от версии Lampa, их серверов и кодеков.
