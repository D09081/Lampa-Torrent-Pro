# Cinema OS для MSX Player

Отдельный веб-лаунчер для Media Station X на LG webOS. Интерфейс Cyber + Hybrid, управление пультом, избранное и список пользовательских источников хранятся локально в браузере.

## Запуск

После публикации GitHub Pages откройте в MSX Player адрес `https://d09081.github.io/Lampa-Torrent-Pro/msx/`.

## Текущий статус

В интерфейсе есть отдельный раздел «Расширения» с карточкой Lampa Torrent Pro и адресом установки. Каталог фильмов в Cinema OS пока демонстрационный: реальные каталоги, поиск метаданных и воспроизведение источников ещё не подключены. Для них нужны отдельные совместимые API/адаптеры; закрытые потоки и DRM не обходятся.
