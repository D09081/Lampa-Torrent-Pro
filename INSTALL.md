# Установка Lampa Torrent Pro 2.0.0

1. Lampa → Настройки → Расширения → Добавить плагин.
2. Вставьте: `https://d09081.github.io/Lampa-Torrent-Pro/plugin.js`
3. Подтвердите установку и перезапустите Lampa.
4. Откройте в левом меню **Cinema OS**.

## Просмотр

Найдите фильм в Cinema OS или штатным поиском Lampa → откройте карточку → **Смотреть**.

- В списке сверху «Рекомендуем»: лучший вариант по вашим настройкам качества и озвучки.
- Онлайн-файлы Internet Archive запускаются сразу. Раздачи запускаются через вашего TorrServer (нужен также Jackett для поиска новых релизов).
- «Официальные сервисы» открывают JustWatch: нужна подписка или приложение сервиса.
- «Онлайн-плагины Lampa» — Online МОД, Showy, Online Cinema, Hermes Movie. Online МОД подключается при каждом запуске, остальные по выбору. Плагин по HTTP потребует подтверждения.

## Настройки

Настройки → Киноцентр · Lampa Torrent Pro: Jackett (адрес, ключ), свой Lampac, регион, качество, озвучка, погода (Белгород по умолчанию), режим производительности.

## Важно

Сторонние плагины выполняют свой код с полными правами в Lampa, подключайте только тем, кому доверяете. Netflix и другие платформы не передают закрытый видеопоток в Lampa. Совместимость проверяйте на своём телевизоре.
