# Установка Lampa Torrent Pro 1.1.0

1. Lampa → Настройки → Расширения → Добавить плагин.
2. Вставьте: `https://d09081.github.io/Lampa-Torrent-Pro/plugin.js`
3. Подтвердите установку и перезапустите Lampa.
4. Откройте меню **Torrent Pro**.

## Просмотр

Найдите фильм встроенным поиском Lampa → откройте карточку → **Где смотреть**.

- Официальные платформы — через JustWatch (нужна подписка/приложение соответствующего сервиса).
- Онлайн-балансеры — пункт «Подключить онлайн-источники». Выберите нужные плагины. Для постоянной работы выбранные расширения будут загружаться при старте.
- Торренты — собственный Jackett и TorrServer; это необязательно.

## Погода

Белгород по умолчанию. Источники: Open-Meteo, wttr.in, резерв 7Timer через CORS proxy. При отсутствии связи появится ошибка, а не выдуманная температура.

## Важно

Showy может требовать активацию через Telegram; Hermes Movie добавляет отдельную кнопку поиска источников. Netflix не передаёт закрытый видеопоток в Lampa. Fovea не добавлен: рабочий адрес Lampa-плагина не подтверждён. Совместимость проверяйте на своём телевизоре.
