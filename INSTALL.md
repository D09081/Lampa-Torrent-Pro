# Установка Lampa Torrent Pro 1.0.0

1. Откройте Lampa → Настройки → Расширения/Плагины → Добавить плагин.
2. Вставьте адрес:
   `https://d09081.github.io/Lampa-Torrent-Pro/plugin.js`
3. Подтвердите установку и перезапустите Lampa.
4. В левом меню откройте **Torrent Pro**.

## Как открыть источники фильма

Найдите фильм встроенным поиском Lampa → откройте карточку → нажмите **«Где смотреть»**. Онлайн-кинотеатры показываются по данным TMDB для выбранного региона. Доступные раздачи загружаются через Internet Archive и настроенный Jackett.

## Jackett и TorrServer

Jackett — необязательный внешний поисковый сервер. Укажите свой адрес и API-ключ в настройках плагина. Для большинства torrent/magnet-раздач нужен TorrServer, запущенный на отдельном устройстве в сети. Укажите адрес этого устройства в настройках Lampa, например `http://192.168.1.10:8090`. Не используйте `127.0.0.1`, если сервер работает не на телевизоре.

## Погода

По умолчанию показывается Белгород. Плагин получает прогноз через Open-Meteo и использует wttr.in как резерв. Если оба сервиса недоступны из сети телевизора, виджет покажет ошибку; проверьте доступ к HTTPS и повторите попытку позже.

## Важно

Это MVP. Реальное воспроизведение зависит от версии Lampa, доступности источника, формата файла и настроек TorrServer. Проверяйте права на каждый материал.
