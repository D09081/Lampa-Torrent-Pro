# Установка Lampa Torrent Pro 2.0.0

Актуальная инструкция: [INSTALL.md](../INSTALL.md).

Адрес установки:

`https://d09081.github.io/Lampa-Torrent-Pro/plugin.js`

Откройте **Cinema OS** в меню, найдите фильм и нажмите **«Смотреть»** на карточке. Раздачи требуют ваших Jackett и TorrServer; онлайн-файлы Internet Archive запускаются без них. Сторонние плагины подключайте на свой риск.
