# Установка

Используйте актуальную инструкцию из [INSTALL.md](../INSTALL.md). Версия плагина: **1.0.0 MVP**.

Плагин добавляется в Lampa через Настройки → Расширения/Плагины → Добавить плагин:

`https://d09081.github.io/Lampa-Torrent-Pro/plugin.js`

Поиск фильмов выполняется штатными средствами Lampa. Чтобы увидеть источники, откройте карточку фильма/сериала и выберите **«Где смотреть»**.

Для большинства torrent/magnet-раздач требуется собственный Jackett и TorrServer. Погода по умолчанию настроена на Белгород; используются Open-Meteo и резервный wttr.in.

Плагин является MVP: совместимость с конкретной сборкой Lampa и LG webOS необходимо проверить непосредственно на устройстве. Права на конкретные файлы и раздачи проверяйте самостоятельно.
