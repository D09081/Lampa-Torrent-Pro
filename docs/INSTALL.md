# Установка Lampa Torrent Pro 1.1.0

Актуальная инструкция: [INSTALL.md](../INSTALL.md).

Адрес установки:

`https://d09081.github.io/Lampa-Torrent-Pro/plugin.js`

Поиск выполняется встроенными средствами Lampa. На карточке фильма используйте кнопку **«Где смотреть»**. Дополнительные онлайн-балансеры подключаются в пункте «Подключить онлайн-источники». Официальные кинотеатры открываются через JustWatch; для воспроизведения требуется подписка/официальное приложение.

Погода: Open-Meteo → wttr.in → 7Timer через CORS proxy. По умолчанию Белгород.

Для большинства torrent/magnet-раздач нужны собственные Jackett и TorrServer. Для десятков VOD-провайдеров можно подключить собственный Lampac backend. Не используйте неизвестные публичные серверы.

Fovea не добавлен без подтверждённого адреса рабочего Lampa-плагина. Сторонние расширения подключайте на свой риск.
