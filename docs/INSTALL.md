# Установка Lampa Torrent Pro

## Установка плагина в Lampa

1. Откройте Lampa → Настройки → Расширения → Добавить плагин.
2. Вставьте адрес:
   `https://d09081.github.io/Lampa-Torrent-Pro/plugin.js`
3. Подтвердите установку стороннего плагина.
4. Перезапустите Lampa.
5. Откройте настройки и найдите раздел «Lampa Torrent Pro».

## Настройка TorrServer

TorrServer должен быть запущен на отдельном устройстве в вашей локальной сети: компьютере, Android-устройстве, NAS или мини-ПК. Телевизор LG подключается к нему по локальному IP-адресу.

Пример адреса: `http://192.168.1.10:8090`

Не используйте `127.0.0.1` на телевизоре, если TorrServer работает на другом устройстве: этот адрес указывает на сам телевизор.

## Текущий статус

Версия 0.1.0 — начальный каркас плагина и allowlist источников. Настройки Lampa регистрируются, но поиск торрентов, проверка доступности сервера и передача magnet-ссылок в TorrServer ещё не реализованы.

## Правовой режим

Проект не индексирует пиратские каталоги. Для каждого конкретного материала требуется проверить правообладателя, лицензию или статус общественного достояния. Нельзя считать весь каталог источника легальным только по названию сайта.
